## Who I am

I'm a software developer with a B.Sc. in Computer Science from Germany.

My background is in backend development — building APIs, designing data models, connecting systems, and keeping things running reliably in production. I've worked in Rust on a real-world booking platform with external API integrations and complex PostgreSQL structures. I take end-to-end ownership seriously: from design to deployment to debugging at 2am.

On the AI side, I don't just experiment — I've shipped things. A CNN-based material classifier for spectroscopy. A deep learning model for music genre classification deployed via REST API on Android. I know what it takes to get a model from notebook to production.

What drives me is the intersection of solid engineering and applied intelligence: systems that are well-structured, integrations that are reliable, and AI that solves a real problem.
